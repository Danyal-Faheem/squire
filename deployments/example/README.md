# Reference deployment

This directory will hold the one worked-example deployment that configures the
Squire engine for a real project, built in the final phase of the plan. It will
contain only configuration — `deployment.yml`, `taxonomy.yml`, `routing.yml`,
`priorities.yml`, and optional `prompts/` overrides — and no engine code.

It is intentionally empty for now; the engine is built generic-first, and this
deployment is added last to prove the engine works for a real project through
configuration alone.
